**对照基准**

- 目标界面：用户提供的方案二主界面截图。
- 当前检查方式：代码结构检查、控件契约测试、依赖导入检查和核心处理流程回归。
- 受限项：macOS 当前 Tk 运行环境无法稳定创建窗口，因此本轮尚无新版 Windows 实机截图，像素级视觉对照暂时阻塞。

**已确认项目**

- 主界面采用浅灰背景、白色圆角卡片、青绿色主操作色和分区留白。
- 顶部五个功能入口均为带本地图标的现代按钮，原回调保持不变。
- 源文件区域改为虚线视觉的点选与拖入区域，删除旧源文件文本框和选择按钮。
- 开始质检、清空文件、输出目录、方案管理和质检人员控件均已重新绘制。
- 结果区按计划动态生成同排统计卡片，包含标题、图标、数量、涉及条数和需关注数量。
- 报送区包含说明、内容预览和复制按钮。
- 日志区包含处理日志、质检报送、校验提醒三个页签；日志采用时间、状态、内容三列表格和语义状态标签。
- 状态栏不显示当前用户，只显示运行状态、当前方案和时间。
- 方案配置、专项配置、备份恢复窗口统一使用圆角卡片、现代输入控件和滚轮滚动区域。
- 程序界面图标均为本地位图绘制，不包含表情字符。

**功能回归**

- 点选文件、拖入文件、清空文件、开始处理和顶部配置入口的事件绑定均通过契约测试。
- 核心处理以样例文件实际运行成功，结果为月度专项 1 条、舆情提醒 12 条、无效舆情 0 条、超时 0 条。
- 处理线程入口和主线程回调结构保持不变。
- `processor.py` 与 `config.json` 未修改。
